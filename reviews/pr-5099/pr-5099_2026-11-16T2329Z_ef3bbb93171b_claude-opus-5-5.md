## Beyond the rules

- Stored bid responses are dropped. For a stored bid response Prebid Server removes the imp from the bidder's request (git ef3bbb93171b:exchange/utils.go:216-218, removeImpsWithStoredResponses at :306-318) and calls MakeBids with the text "Stored bid response for impression id: <id>" as the request body and no ImpIDs (git ef3bbb93171b:exchange/bidder.go:801-808, reached from :255-266 and :306). MakeBids needs both the outbound body (git ef3bbb93171b:adapters/growzee/growzee.go:120) and the imp in the request (:125-129, :139), so it returns no bids for any stored bid response. TestMakeBidsOutboundWithoutOneImp (adapters/growzee/growzee_test.go) asserts that drop for a body that is not JSON.
- The rewarded signal is removed. growzee declares no openrtb.version, so Prebid Server downgrades its requests to 2.5 (git ef3bbb93171b:exchange/utils.go:223-225), which moves a rewarded imp's rwdd to imp.ext.prebid.is_rewarded_inventory and clears rwdd (git ef3bbb93171b:openrtb_ext/convert_down.go:158-174). git ef3bbb93171b:adapters/growzee/growzee.go:80 deletes imp.ext.prebid, so the rewarded flag never reaches the endpoint. No fixture sets rwdd or imp.ext.prebid.
- The bid type is guessed on multi-format imps. With no mtype, or one other than 1, 2 or 4, getBidType (git ef3bbb93171b:adapters/growzee/growzee.go:167-174) gives banner for any imp with a banner (banner+native included), video for a video+native imp, and video on a banner+video imp only when the adm holds "<VAST" in its first 512 bytes (:178-180). A native bid on a banner+native imp is typed banner; a video bid with an empty adm (markup by nurl) on a banner+video imp is typed banner. No fixture has a banner+native imp.
- mtype is trusted even when the imp lacks that format: supplemental/mtype-banner.json expects a banner bid on a video-only imp. Core does not check a bid's type against its imp. Whether to refuse such a bid is a policy question, not raised in the comment.
- supplemental/unsupported-media-type.json sends an audio-only imp; Prebid Server removes audio for a bidder that declares none, so that input cannot reach the adapter in production.
- git ef3bbb93171b:adapters/growzee/growzee.go:121 reports a failure to read the outbound body as FailedToUnmarshal, an error about the bidder's response.
- The bid to imp binding aleksUIX asked for is in place at the head (git ef3bbb93171b:adapters/growzee/growzee.go:114-144), covered with and without mtype by supplemental/cross-impid.json and cross-impid-mtype.json.
